# Лабораторная работа 4, вариант 14

Консольная программа для расчёта режимов фрезерования.

## Запуск

В VS Code нажмите `F5` или выполните в терминале:

```bash
python3 main.py
```

Тесты запускаются так:

```bash
python3 -m unittest tests -v
```

## Данные варианта

| Материал | Скорость резания |
|---|---:|
| Сталь | 80 м/мин |
| Алюминий | 250 м/мин |
| Чугун | 60 м/мин |

Допустимые значения: `D` от 5 до 200 мм, `z` от 1 до 20, `Sz` от 0.01 до 0.5 мм/зуб, `t` от 0.1 до 10 мм.

## Формулы

```text
n = 1000 · V / (π · D)
Sмин = Sz · z · n
MRR = t · (D / 2) · Sмин / 1000
```

Классификация глубины: `t < 1` — чистовая, `1 <= t <= 3` — получистовая, `t > 3` — черновая.

## Файлы

- `main.py` — главный цикл программы.
- `constants.py` — константы и диапазоны.
- `validation.py` — проверка и ввод данных.
- `operations.py` — формулы и классификация.
- `menu.py` — меню материалов через `match-case`.
- `logger.py` — журнал ошибок.
- `tests.py` — автоматические тесты.
